# 🧊 Floaty Toolbar

> A sleek, modern, and lightweight floating selection toolbar for Obsidian.  
> Bringing essential formatting tools directly to your fingertips.

---

## ✨ Features

- **Context-Aware**: Only appears when text is selected. Stays hidden to keep your writing environment distraction-free.
- **Minimalist UI**: Minimalist design language that seamlessly integrates with any Obsidian theme.
- **Effortless Formatting**: Instantly apply **Bold**, *Italic*, Highlights, and Headers without remembering complex hotkeys.
- **Desktop Optimized**: Fine-tuned for a smooth, "floaty" interaction on Windows, macOS, and Linux.

## 🛠️ How to Use

1. **Select Text**: Use your mouse to select any text in your Obsidian editor.
2. **Floaty Appears**: The toolbar will instantly pop up above your selection.
3. **Format Away**: Click any icon (Bold, Italic, Code, etc.) to apply formatting immediately.
4. **Dismiss**: Click anywhere else or press `Esc` to hide the toolbar.
